PhotoCast · Rate a forecast · v1

"How was it?" in the location popup

The first step is in-app only, for Pro and Admin. When a user opens any location whose sunrise or sunset has passed, the popup (a bottom sheet on phone) shows one row: five stars and "Didn't see it". One tap records it, and the row collapses to the answer with a Change button. The forecast star stays where it already is, above the row. There are no notifications, no new screen and no history. Admins also see everyone's ratings for that event. Lite users see the row locked, with the Pro pill.

04 · Decisions

What this version does and doesn't do

  • One row, no modal. The existing OutcomeModal (went out, sliders, notes) stays admin tooling. This row replaces it as the everyday path.
  • Forecast visible before and after, as chosen. It is already the popup's headline star, so the row adds no second copy of it and no comparison or verdict.
  • "Didn't see it" is recorded as a not-seen outcome and can be changed like a star.
  • Optimistic save. The row collapses on tap. If the save fails it reopens with the amber line, the only amber in the flow.
  • Sunrise first. The popup shows one event at a time; where the sheet lists both, sunrise's row comes first.
  • Going back. The existing date strip already dims past days behind a divider. Picking one opens that day's popup with the same row, and "any time" means no cut-off.
  • Map only. The Plan view has no past windows, so rating lives in the map's location callout. See Outcome Prototype v2, which uses the current map window control: step back with ‹ or pick from the menu's "Earlier" group.
05 · Resolved

Answers folded in

  1. Past dates: yes, through the date strip (phone state 9). How far back depends on how many past dates the forecast endpoint returns. Older days need it to return more.
  2. Storage: key is user + location + date + event. Star is 1–5, or null when not seen. Re-rating updates the row.
  3. Which forecast: the last run before the event, even when it's stale after a batch failure. The run time is stored with the rating and shown to admins, so an old forecast is visible as the cause.
  4. Admin list: shows usernames.
  5. Drilldowns: not in Plan, which has no concept of past windows. The map only.
