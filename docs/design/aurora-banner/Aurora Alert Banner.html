Aurora alert: map thumbnail on desktop, glow strip on phone

One banner component with two layouts. On desktop and iPad it shows tonight's aurora field next to the alert, so it answers where as well as how strong. Until per-location scores exist it shows Kp in the same slot instead of an empty map. On phones it collapses to the 56px glow strip. Severity uses the aurora ramp throughout: Moderate is teal-green, Strong is full aurora green.
