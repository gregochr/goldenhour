Signal decay — why the 60th night of NLC season should say nothing

You are right that hot topics are coincidences. But a season is not a coincidence — it is a background condition, and a notice that fires every night for nine weeks stops being information by about night four. The fix is to make an event's treatment a function of how much tonight beats the baseline, and of how many times you have already been told. Drag the night and watch the same event demote itself.

The rule set this implies

  1. Speak to the delta, not the fact. "It is NLC season" is true for 62 nights and useful on one of them. "Clearest northern horizon in 11 nights" is only ever said when it is worth saying — and it carries the season inside it.
  2. Count what you have already shown. Treatment steps down with exposure: strip, then row, then badge, then silence. The season does not get to reset the counter; only a new best does.
  3. Silence is a state you design. A suppressed event still leaves one quiet line with a link, so a keen user can always find it. Absence should read as "nothing new", not as "broken".
  4. A coincidence overrides decay. Night 55 with a clear horizon and peak tide is a trip, not a repeat. Two attributes on one window re-earn the strip regardless of how long the season has run.
  5. Seasons belong in Coming up. The standing fact — dates, what it is, how many nights left — lives there permanently. Plan only ever carries tonight's delta.
