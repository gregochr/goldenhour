Scoring happens per site and window, so one user and a thousand users buy the same generation. What actually scales with users is small and mostly one-off: drive times from a new home address, notification sends, and — only if you let it — personalised prose. Drag the users slider and watch cost per user collapse while total cost barely moves. Unit costs are placeholders; put your real ones in and the shape holds.
