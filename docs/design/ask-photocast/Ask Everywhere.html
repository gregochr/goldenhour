Ask from any tab

Three ways to reach Ask from Plan and Coming up as well as the Map. In all three, the suggested questions match the tab you're on, and every answer can jump to the window in Plan or show the picks on the Map. Switch tabs inside a phone, or use the bar below to switch all three.

All phones:Answers here are scripted.
Option A

Ask button in the masthead

One button, always in the same place, next to settings. It opens a sheet over whatever tab you're on.

  • Works on every tab with no layout changes
  • Easy to overlook, and it competes with the masthead
Option B

Ask bar on every tab

The Map's ask bar is now at the bottom of every tab, with a prompt that matches the tab.

  • Easiest to find, and the same on every tab
  • Takes 58 px off the bottom of every tab
Option C

Ask as its own tab

A fourth tab with the full conversation and recent questions. Answers link out to Plan and Map.

  • Room for history and follow-up questions
  • Takes you away from what you were looking at, so the questions can't use it
