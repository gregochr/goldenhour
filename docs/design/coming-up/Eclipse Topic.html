Yes, and you already built the machinery for it. Coming up in Plan Window First splits events into Almanac — fixed by orbital mechanics, plan months out — and Forecast — firms up ~3 days ahead. An eclipse is the purest almanac event there is: NASA publishes contact times to the second for every eclipse through 3000 AD. Tomorrow's was computable before PhotoCast existed.

So this isn't a new pattern. It's a new event type in an existing rail, plus one thing the rail can't currently express: some almanac events are routine and some are once in a lifetime, and a spring tide run shouldn't sit at the same weight as the deepest eclipse since 1999.

Almanac events are fixed by orbital mechanics — plan months out. Forecast events firm up 3 days ahead. Anything live gets promoted to the top of Plan on the day.

The only new ingredient is the rare treatment — a red left rule, a warm wash falling off to the right, and a once line naming the recurrence interval. It fires when an almanac event's return period exceeds roughly a decade, so it stays scarce by construction: eclipses, a Great Conjunction, a genuinely exceptional tide. A spring tide run never earns it.

What changes is the quality: colour goes metallic, shadows sharpen to knife edges, and pinholes between leaves cast crescents on the ground. Two calls for you.
  1. Does rare earn its keep? It's one more visual state in a rail that's already doing two. The alternative is no new state and the recurrence interval living in the sub-line as plain text — cheaper, quieter, and probably under-sells an event this uncommon.
  2. Promotion timing. The rail says live events get promoted to the top of Plan on the day. An eclipse at 19:13 is worth promoting the evening before, since the trip has to be decided by then.
