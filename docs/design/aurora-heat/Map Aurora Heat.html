Aurora on the heat field, with its own ramp

Aurora mode drops the medallions and paints the same field as sunrise and sunset: each location's own aurora rating, blended where they overlap, coverage-clamped so empty ground stays empty. What changes is the colour scale. Aurora runs from night slate through teal to aurora green at 5★, so the mode is obvious at a glance and a good aurora night can never be mistaken for a good sunset. The Kp viewline sits on top as the physical boundary the scores respect.

Why a separate ramp

The mode should announce itselfThe shared temperature ramp puts red at 5★. On an aurora night red would read as "hot sunset", and the screen would look like the Sunset tab with different numbers. A green field is unmistakably aurora.
Brightness ranks it for freeThis ramp gets brighter with every step, so on the dark basemap the best places literally glow. The shared ramp's darkest colour is its best score and needs the bloom pass to compensate.
Low end means "dark sky, no show"1★ is a dim slate, not red. A poor aurora night is not a failure state, just an ordinary night, and red would overstate it. It stays visible so "poor" still differs from "no data".
One kernel stillOnly the score source and the ramp change. Cull, bucketing, coverage clamp, confidence haze and zoom handover are untouched.
