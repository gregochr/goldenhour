### Added — "Coming up" day chips mark the supermoon night and the tide peak on a merged card

When a supermoon falls on a spring or king tide run the merged card's day chips now carry the served marks: a `full moon` line on each moon night and a `peak` line on the run's true peak day, each coloured by its own topic family, and named in the chip's accessible name (`Show coastal spots for Tue 27 Oct, peak day, full moon`). On a merged card the word "peak" appears only where the server marked a true peak, so a run with partial tide coverage no longer shows a peak it does not have. The peak chip takes the card's accent colour rather than gold, so it is not drawn in the moon's gold beside a gold `full moon`, and a merged run of up to 14 days gets its chip row (other cards keep 10). Unmerged cards are unchanged. Tested, not seen in a browser.
