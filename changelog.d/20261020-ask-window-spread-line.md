### Added — the server's figures beside Ask PhotoCast's answer

Under an Ask answer's summary, one quiet line per window the answer may have quoted now shows the
served rating distribution the model was reading — `Sat sunset · 180 rated across every region ·
2 at 4★+`, with `· N at 5★` when any place is, `none at 4★+` when none is, and the scope's region
names in place of "every region" for a question about an area — so a count the model states can be
checked against the server's own figure on the same screen. A window nobody has rated draws no line;
an answer whose carried windows are all unrated says "Nothing rated" once; an answer that carries no
windows (every Ready answer stored before the spread was served, and every can't-answer) is drawn
exactly as before. It is on every surface (the phone sheet, the tablet sheet, the dock and the phone
Map peek), for every role, and is deliberately not the Plan card's reach-gated histogram. The figures
are never echoed on a follow-up's thread. No backend change.
